❯ I want to maek a PR to rust-lang/rust. What should I do first?

⏺ First: the LLM disclosure policy in this repo's CLAUDE.md applies. Before making any code changes here, a reviewer must agree ahead of time to
  review an LLM-assisted PR. New contributors especially must talk to a reviewer first.

  Once that's sorted, the usual first steps:

  1. Find or file an issue describing the change
  2. Ask on Zulip (#new-members or the relevant team channel) if unsure of scope or approach
  3. Make the change, run ./x.py check and relevant tests
  4. Open the PR with disclosure in the description
